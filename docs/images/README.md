# 画面画像

[READMEへ戻る](../../README.md)

このリポジトリの実装をローカルで起動し、2026-11-09にChromeで撮影した画面です。UIを別途描いたモックアップではありません。

- `punch.webp`: 丸い打刻ボタン、今日の記録、共通ヘッダーから開ける日別メモ。
- `history.webp`: 週のタイムライン、日付ごとの記録、全文表示の作業メモ。
- `stats.webp`: 時間と一致する横の目盛り線、日別の表、開いたままのメモ。

表示名・記録・メモ・プロフィール画像はすべて表示用です。本人のアカウント、認証情報、本番DB、個人の記録は使用していません。合成データは画像以外に含めません。撮影日は暦日、画面の日付は設定した日の区切りによる記録日です。

画像はREADMEから相対パスで参照します。UIを変更したときは、ローカルの表示用データを使い、個人情報を写さず更新してください。

透明背景・#2563ebの現行ロゴと初期カラーで撮影しています。
