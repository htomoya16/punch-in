# 画面画像

[READMEへ戻る](../../README.md)

このリポジトリのPunch inの実装をローカルで起動し、2026-11-04にChromeで撮影した画面です。UIを別途描画したモックアップではありません。

- `punch.webp`: 打刻、計測中の経過時間、一括操作のアウトラインボタン、保存チェック付き日別ブロックメモ、分単位の時間表示と右寄せの作業時刻。
- `history.webp`: 横スクロール・拡大できる7日分のタイムライン、閲覧日の強調、打刻ごとに分かれたメモ、独立した目盛り行。
- `stats.webp`: 作業時間で統一した週のグラフ、今日の行を強調した日別集計表。

名前・記録・メモはすべて表示用のサンプルです。表示名はDemoとし、本人のアカウント、認証情報、本番DB、個人の記録は使用していません。撮影用のローカルデータはこのディレクトリに含めません。

画像はREADMEから相対パスで参照します。UIを変更した場合は対応する画像を撮り直してください。

時間の表示は「N時間MM分」へ統一し、単位を小さくした状態で撮影している。

最新画像は所要時間をHH:mmとし、記録の開始終了に時計アイコンを添えた画面。

最新の画像では所要時間をHH:mmで表示し、開始・終了の範囲に時計アイコンを付けている。
