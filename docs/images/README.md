# 画面画像

[READMEへ戻る](../../README.md)

このリポジトリのPunch inの実装をローカルで起動し、2026-11-04にChromeで撮影した画面です。UIを別途描画したモックアップではありません。

- `punch.webp`: 打刻、計測中の経過時間、一括操作のアウトラインボタン、保存チェック付き日別ブロックメモ。
- `history.webp`: 上部に固定したタイムライン、薄い色で区切った日付行、記録ごとのメモ。
- `stats.webp`: 計上時間で統一した週のグラフ、今日の行を強調した日別集計表。

名前・記録・メモはすべて表示用のサンプルです。表示名はDemoとし、本人のアカウント、認証情報、本番DB、個人の記録は使用していません。撮影用のローカルデータはこのディレクトリに含めません。

画像はREADMEから相対パスで参照します。UIを変更した場合は対応する画像を撮り直してください。
