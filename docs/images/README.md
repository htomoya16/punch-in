# 画面画像

[READMEへ戻る](../../README.md)

Punch inの実装（7b298e9）をローカルで起動し、2026-11-03にChromeで撮影した画面です。UIを別途描画したモックアップではありません。

- `punch.webp`: 打刻、計測中の経過時間、日別Markdownメモ。
- `history.webp`: タイムライン、記録一覧、記録ごとのメモ。
- `stats.webp`: 週のグラフ、日別集計表、種類別の合計。

名前・記録・メモはすべて表示用のサンプルです。表示名はDemoとし、本人のアカウント、認証情報、本番DB、個人の記録は使用していません。撮影用のローカルデータはこのディレクトリに含めません。

画像はREADMEから相対パスで参照します。UIを変更した場合は対応する画像を撮り直してください。
